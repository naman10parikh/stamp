# stamp — BRAND

> Name rationale, tagline, palette, and landing copy for the Energy fleet's compliance employee.
> Powered by Energy.

## Name rationale

**stamp** (locked). A *stamp* is the mark of approval an authority presses onto a document — the exact noun for a
compliance / attestation employee. It carries a deliberate **double meaning**: it is also the thing stamp *refuses*
to be a *rubber* version of. A rubber stamp signs off on anything; stamp **vets the auditor, verifies vendor
independence, and routes a human to sign every consequential attestation** (OPINIONS O3/O22/O24/O25). The name is
the promise: a *real* mark of approval, backed by assembled evidence — never a rubber one.

It fits the Energy naming family (D4): one short, light, relatable, animate word that names the element of the
workflow it automates — alongside its siblings **badge** (auth), **rocket** (deploy), **penny** (payments),
**pixel** (frontend), **pebble** (mobile), **turbo** (backend), **acorn** (database).

## Tagline

> **"Audit-ready evidence, assembled and proven — never a rubber stamp, never 'we're compliant.'"**

The tagline encodes stamp's two hardest-held stances in one line: it assembles *evidence* (not a self-issued
badge), and it refuses the two slop claims — being a *rubber* stamp (O3/O25) and saying *"we're compliant"* before
a CPA firm signs (O24). Secondary line for capability framing: *"badge = the connection; stamp = the program that
decides we need it and proves it to the auditor."*

## Symbolic connection to the workflow

The pressed mark = the assembled, control-mapped, hash-chained evidence package. The *refusal to be rubber* = the
human-signs-the-attestation gate and the vet-the-auditor discipline. The boundary line (badge owns the mechanism;
stamp owns the proof) is stamp's identity, not a footnote.

## Palette (Energy design system — warm, editorial, grounded; NOT generic AI purple)

| Token            | Value                | Use                                              |
| ---------------- | -------------------- | ------------------------------------------------ |
| Background       | **`#141312`** (warm black, NOT pure black) | cockpit + all surfaces |
| Surface          | `#1c1a18`            | cards, panels                                    |
| Text (primary)   | `#e8e4dd` (zinc-100-ish, never pure white) | body                            |
| Accent           | **amber** `#f59e0b`  | the "stamp" mark, active states, the seal motif  |
| Severity / fail  | `#dc2626`            | gap findings, boundary-FAIL banners              |
| OK / audit-ready | `#16a34a`            | "audit-ready evidence assembled" (never "compliant") |

- **Type:** **Instrument Serif** for display/headings (the editorial, document-authority feel — the stamped seal),
  **Poppins** for body. The serif + sans pairing is the single highest-impact anti-AI-slop choice.
- **Motif:** an amber wax/ink **seal/stamp** mark for the brand glyph; asymmetric bento layout in the cockpit
  (Brain · Runs · Evals · Ask-the-employee). No generic purple/pink gradients.
